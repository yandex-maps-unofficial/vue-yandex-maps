# Режим Vapor

Библиотека собирается в двух режимах: Vapor и стандартном.

Для того, чтобы использовать Vapor, измените импорт компонентов на `vue-yandex-maps/vapor` - остальные импорты оставьте без изменений.

Обратите внимание, что все примеры используют импорт из `/vapor` - но вы вольны выбирать, в каком режиме работать.

Для работы библиотеки **не требуется** `vaporInteropPlugin`.
